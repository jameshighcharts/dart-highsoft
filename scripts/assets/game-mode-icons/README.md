# Game icon sources

AI renders of the glass dartboard icons. Each `<name>.jpg` has a *painted*
checkerboard rather than an alpha channel; `scripts/key-game-mode-icons.py`
mattes it onto real transparency and writes `public/game-icons/<name>.png`
(512x512, centred). Names match the app's GameType keys.

```bash
npm run icons:game-modes                       # all sources
python3 scripts/key-game-mode-icons.py ~/Downloads/new.jpg x01   # one file, explicit name
```

`bengt.png` and `_sheet-v1.png` already have real alpha and are used as-is (the script only processes `.jpg`); `x01.png`,
`new-match`, `tournament` and `practice` in `public/game-icons` still come
from earlier sheets and are not regenerated by the script.
